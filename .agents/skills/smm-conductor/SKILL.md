# SMM Conductor

На первом содержательном запросе выбрать нужный шаг. Сохранять весь запрос, дату, пути, URL, ограничения и предыдущие разрешения.

Порядок:
1. Явная команда, правка файлов/навыков, диагностика или вопрос о состоянии проекта — выполнить сам запрос. Наличие URL не превращает техническую задачу в публикацию.
2. Просьба выпустить материалы, назначить YouTube/Telegram/Дзен или обработать уже полученный YouTube URL — `../publish-from-script/SKILL.md`. Существующий URL не означает повторную загрузку.
3. Просьба смонтировать raw-видео — `../render-docx-visuals/SKILL.md`, если DOCX содержит изображения; иначе проверить условия `../render-with-visuals/SKILL.md`.
4. Тема, идея, кейс или просьба написать сценарий для аудитории — `../video-script/SKILL.md`. Передать всё сообщение, включая дату публикации.
5. Остальное — обычная работа с запросом.

Не игнорировать комментарии пользователя возле URL. Не переспрашивать, является ли очевидная тема темой видео. На продолжении задачи учитывать её текущий шаг.
