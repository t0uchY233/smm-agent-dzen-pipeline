# Stage 6 — Metrics & process optimization

Artifact: `06-retro.md` with `## Метрики` generated by `rails.py metrics --write`. Gate: Узкое место + Что улучшить filled.

Why: you may think the agent sped things up because it writes code fast; metrics often show everything waits on manual review (slide "Скрытое узкое место"). The process must be measured.

Steps:
1. `rails.py metrics --write` — time per stage, share, number of back-steps and their reasons.
2. Узкое место: name the slowest stage and the real reason (waiting for the human? unclear AC? flaky tests?).
3. Что улучшить: ONE concrete change — a rule added to `.rails/context.md`, a test helper, smaller plan steps, a pre-agreed review checklist.
4. Apply context improvements now (edit `.rails/context.md`) so the next task starts smarter.

Exit: `rails.py advance` → task done.
