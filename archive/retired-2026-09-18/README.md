# Исторические интеграции

Сохранены без запуска: n8n workflows, шаблон Sheets, инструменты WordPress/OpenRouter/RSS и тесты прежнего контракта. Часть старых тестов ссылается на прежние пути и не предназначена для запуска в активном проекте.

Не импортировать эти workflows и не запускать утилиты как часть нового выпуска. Новый процесс: `docs/specs/content-release.md`, локальные клиенты в `tools/publishing_*.py`.

Перенос локальных файлов не отключает когда-либо развёрнутый облачный workflow. Перед внешним тестовым выпуском проверить, что старые задачи не публикуют те же материалы. Доступ к облачному n8n в этой реализации не использовался.
