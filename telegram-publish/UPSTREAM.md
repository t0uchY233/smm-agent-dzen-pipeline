Allowlist upstream при отсутствии настройки отключён; это не замена проверке утверждённого канала и ревизии.

## Чего не берём

Не переносим MCP-сервер, runtime целиком, управление контактами и папками, транскрибацию. Они не нужны для отложки выпуска. Агент не должен получать свободный инструмент отправки в обход утверждения ревизии. Адаптер T3 будет вызываться из общего CLI с проверкой материалов, разрешённого чата и состояния отправки.

## Атрибуция и сопровождение

При переносе кода соблюдаем Apache-2.0 §4: сохраняем `LICENSE`, исходные уведомления об авторских правах и атрибуцию; изменённые файлы явно помечаем как изменённые. Если upstream добавит `NOTICE`, переносим применимые уведомления при обновлении; на зафиксированном commit такого файла нет. Дословно скопированные и адаптированные части следует различать.

Риск из плана проекта: Telethon архивирован в 02.2026. GitHub API при этой проверке подтверждает `archived: true`, но не дату архивации. Для T3 предусмотрен пин `telethon>=1.45,<2`; зависимости этой задачей не меняются. Запасной вариант: https://github.com/kurigram-org/kurigram — отдельная миграция с проверкой сессий, отложки и совместимости, не автоматическая замена.
