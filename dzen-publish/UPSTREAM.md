# Источник и локальные расширения

Основа: https://github.com/Andrrreyiv/dzen-publish
Зафиксированный upstream commit: `a6bbc78b151523a195c21570f14985b3f2615d29`.

Этот каталог — сопровождаемая локальная копия. Сохраняем Playwright/CDP, авторизованный Chrome, штатный редактор, заполнение тела до заголовка и обработку диалогов. Обновления upstream переносим после сравнения и BDD-проверок из ветке разработки `rework/publishing-solyanka`; автоматической перезаписи каталога нет.

Расширения проекта: ограниченное подключение и healthcheck; безопасный запуск отдельного профиля Chrome; локальные изображения и упорядоченный DOCX; Word rich paste; активные ссылки; московская отложка; связь с утверждённой ревизией выпуска; независимая сверка результата.

Общий CLI в `tools/publish_release.py` вызывает функции этого транспорта через [`tools/publishing_dzen.py`](../tools/publishing_dzen.py). Другой механизм редактора для основного маршрута не создаётся. Browser Use/Computer Use — только восстановление после конкретного сбоя основного пути.

Upstream ориентирован на Windows. Поддержка Linux, расписание, изображения и контракт выпуска — локальные расширения, их работоспособность проверяется отдельно. Локальные тесты не подтверждают текущую разметку рабочего Дзена.

Уточнения маршрута после реальной публикации 2026-10-01: адресное закрытие donation-promo перед созданием; ожидания меню/редактора вместо координат и фиксированных пауз; точное нормализованное совпадение заголовка; локализованные даты очереди и относительная дата авторского превью; сравнение соседних абзацев с сохранением границ изображений; загрузка нижних изображений прокруткой. Проверки полного текста, пяти ссылок, московского времени и утверждённой revision не ослаблены. Поведенческие регрессии используют изолированный Chromium (проверки наблюдения в ветке разработки `rework/publishing-solyanka`); внешний запуск проверки существующего выпуска не создаёт публикаций.

CDP-хелпер `tools/chrome_cdp.py`, Windows helper `ensure_cdp_chrome.ps1` и read-only функция `open_channel(page, channel_url=None)` перенесены из `issue-2-auth` (PR № 12/13). Остальной транспорт и адаптер выпуска взяты из `wip/bdd-tests-dzen-route`. Навигация ожидает `domcontentloaded`; закрытие donation-promo остаётся только в создании черновика. Безопасность endpoint и режима external проверяется тестами `test_chrome_cdp.py` в ветке разработки `rework/publishing-solyanka`.

## Лицензия

У Andrrreyiv/dzen-publish нет файла лицензии (проверено 2026-11-02 через GitHub API). Формально права на копирование не подтверждены. Решение проекта — запросить лицензию у автора; до ответа существующая копия сохраняется с этой пометкой. Запрос автору в рамках этой задачи не отправлялся.
