# Маршрут публикации в Дзен

Этот документ дополняет `.agents/skills/dzen/SKILL.md` и закрепляет рабочий маршрут проекта для любой публикации в Дзен: немедленной, тестовой, с изображением или отложенной.

1. Подготовить одну ревизию: заголовок, текст, локальные медиафайлы, канал, видимость и время. В конец каждой статьи добавить ровно один блок из `.agents/skills/dzen/references/required-footer.md`, отделив его пустой строкой; если блок уже завершает текст, не дублировать. Перед отправкой проверить, что все пять ссылок активны в предпросмотре. Для отложки использовать `Europe/Moscow`, если пользователь не указал другую зону, и оставлять не меньше минуты до срока.
2. Проверить авторизованный браузер. Приватная конфигурация сессии хранится только в `.local/auth/dzen_config.json`; cookies и CSRF не запрашиваются и не выводятся в чате. При 403 или истёкшей сессии остановиться до повторного входа в браузере. Сообщение конкретного браузерного инструмента о политике безопасности не означает, что Дзен недоступен: до остановки выполнить preflight CDP на `http://127.0.0.1:9222/json/version` по `.agents/skills/dzen/references/cdp-recovery.md`. Если порт не отвечает, агент сам запускает `dzen-publish/ensure_cdp_chrome.ps1`, повторяет проверку и переходит на локальный CDP-путь.
3. Проверить локальные вложения до открытия редактора. Для изображений допустимы `.png`, `.jpg`, `.jpeg`, `.bmp`, `.webp`, `.gif`. Одобренное изображение обязательно должно попасть в публикацию. У DOCX со встроенными изображениями сохранить manifest `tools/extract_docx_dzen_sequence.py`, но вставлять основным способом через `tools/copy_docx_body_to_clipboard.ps1`: Word передаёт текст и рисунки одним rich-clipboard фрагментом в исходном порядке.
4. Открыть редактор канала только через основной путь репозитория: запустить `dzen-publish/ensure_cdp_chrome.ps1`, затем выполнить `dzen-publish/publish_dzen.py --healthcheck` и только после успешной read-only проверки вызвать `publish_dzen.py <article> --paste-docx <docx> --expected-pasted-images <count> --footer-file <footer> [--schedule YYYY-MM-DDTHH:MM]` для DOCX или `--media ...` для независимых вложений через Chrome CDP `http://127.0.0.1:9222`. Health-check ограничен по времени и повторяет подключение один раз; при его таймауте helper запускается повторно и health-check выполняется ещё один раз. Не выбирать Browser Use или Computer Use для создания, загрузки или отложки, пока этот путь не завершился конкретной ошибкой редактора после успешной проверки. Дзен получает единый Word rich paste и поэтому сохраняет изображение сразу после соответствующего фрагмента, а не пакетом. Перед отправкой дождаться `[data-testid="article-image-item"] img`, сверить количество, ненулевые `naturalWidth`/`naturalHeight` и контекст текста до/после каждого изображения.
5. До внешнего действия показать точные материалы, канал, вложения, видимость, дату, часовой пояс и revision. Немедленная открытая публикация и отложка выполняются только по явному поручению/утверждению этой версии.
6. Для немедленной публикации оставить «Опубликовать позже» выключенным. Для отложки включить его, ввести утверждённые дату и время, сверить отображаемое расписание и отправить один раз. Таймаут до открытия редактора обрабатывается health-check recovery и не переводит выпуск сразу в `failed`; сбой после изменения черновика или неоднозначный ответ требуют сверки существующего объекта и не допускают слепого повтора отправки.
7. Независимо проверить итог: URL или статус отложки, заголовок, текст, финальный блок с пятью активными ссылками, канал, видимость/время и количество изображений. Сохранить доказательства в `.tmp/publishing/<release-base>/` и `publish-log.md`; локальный клик сам по себе не считается публикацией.

Не предполагать наличие upstream `scripts/publish.py` и не придумывать API. Основной путь — `dzen-publish` с CDP и `--schedule` для отложки; Browser Use или Computer Use допустимы только после фактической ошибки этого скрипта. Объявить выпуск заблокированным можно только после фактической недоступности обоих путей. Частичный успех одной площадки не является основанием повторять действия на другой.
